## 核心流程

### 1. 代码索引

```
扫描代码目录 → 过滤无用文件 → AST 提取函数 → 语义切片
    → BGE-M3 向量化 → 存入 ChromaDB → 更新 SQLite 元数据
```

### 2. 面试流程

```
[IDLE] → 上传简历 → [RESUME_ANALYZED]
    → 创建会话 → [QUESTIONING] (循环)
        → 根据技能指针 + RAG 检索 → 生成问题
        → 用户回答 → 评估打分 → 决策(追问/换题)
    → 达到轮次 → [TERMINATED] → 生成报告 → [DONE]
```

### 3. 问题生成机制

基于以下特征动态生成，杜绝硬编码：

- 当前考察技能点（技能指针轮转）
- 候选人工作年限对应的难度等级
- RAG 检索到的项目代码片段
- 最近 3 轮对话历史摘要

## 数据模型

### 关系型数据库 (SQLite)

- `projects` —— 代码库元信息
- `resumes` —— 简历解析结果
- `interview_sessions` —— 面试会话状态
- `messages` —— 对话记录与评分
- `function_graph` —— 函数调用关系图谱
- `cram_tasks` —— 八股文生成任务

### 向量数据库 (ChromaDB)

- Collection 命名：`project_{project_id}`
- 向量维度：1024（BGE-M3）
- 相似度：余弦相似度
- 检索策略：MMR（最大边际相关性），Top-5
